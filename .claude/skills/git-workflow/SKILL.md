# Git

- فرع لكل مهمة: feat/…، fix/…، chore/…. لا عمل مباشر على main.
- Conventional Commits: `feat(auth): إضافة تسجيل الدخول بـ Google`. سطر أول ≤ 72 حرفًا، ثم سبب التغيير إن لزم.
- commit صغير ومنطقي واحد لكل تغيير مفهوم؛ لا "fix" و"wip" في التاريخ النهائي.
- قبل commit: لا ملفات مولّدة، لا أسرار، لا console.log. افحص `git diff --stat`.
- PR: عنوان واضح، وصف: ماذا/لماذا/كيف اختُبر، لقطة شاشة للواجهات.
- التعارضات: افهم الطرفين قبل الحل، وشغّل الاختبارات بعده.
- الإصدارات: وسم semver (v1.2.0) + CHANGELOG.md مُحدّث.
- لا force push على فروع مشتركة. `--force-with-lease` على فرعك فقط.
- عند التسليم: اذكر اسم الفرع ورابط PR إن وُجد.
