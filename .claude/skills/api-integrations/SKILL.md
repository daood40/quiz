# دمج الخدمات الخارجية

- اقرأ توثيق الخدمة الحالي أولًا (ابحث عن الإصدار)؛ لا تعتمد على الذاكرة في أسماء الحقول.
- غلّف كل خدمة في وحدة واحدة (services/stripe.ts) بواجهة بسيطة؛ لا نداءات متناثرة.
- المفاتيح في البيئة، ومفاتيح test/live منفصلة.
- Webhooks: تحقق من التوقيع، اجعل المعالجة idempotent (خزّن event id)، رد 200 سريعًا ونفّذ في الخلفية.
- إعادة المحاولة مع تراجع أسي للأخطاء 5xx والشبكة فقط، لا للـ 4xx.
- المهلات (timeout) صريحة لكل نداء.
- سجّل الطلب/الاستجابة بدون أسرار أو بيانات بطاقات.
- الدفع: لا تلمس أرقام البطاقات أبدًا؛ استخدم Checkout/Elements المستضافة. احفظ المبالغ بأصغر وحدة (هللة/سنت).
- OAuth: PKCE للتطبيقات، state للحماية، وتخزين refresh token مشفرًا.
- اختبر بالوضع التجريبي (sandbox) وأرفق خطوات الاختبار في الرد.
