# ميزات الذكاء الاصطناعي

## الأساسيات
- مفاتيح API من البيئة فقط، ولا تُرسل للواجهة أبدًا؛ كل نداء يمر عبر الخادم.
- اختر أصغر نموذج يحقق الجودة المطلوبة، ووثّق السبب.
- استخدم streaming للمحادثات، وأظهر حالة التحميل.
- حدّد max_tokens وtimeout وإعادة محاولة مع تراجع أسي.

## الأوامر (Prompts)
- تعليمات النظام منفصلة عن مدخل المستخدم، ومدخل المستخدم داخل وسم واضح.
- اطلب مخرجات مهيكلة (JSON) عند الحاجة وتحقق منها بمخطط قبل الاستخدام.
- احفظ الأوامر في ملفات منفصلة ومُصدّرة (prompts/)، لا داخل الكود.
- للعربية: اذكر اللغة صراحة في تعليمات النظام واطلب فصحى مبسّطة إلا إن طُلب غير ذلك.

## RAG
- التقطيع: 300–800 رمز مع تداخل 10–15%، واحفظ metadata (المصدر، الصفحة، التاريخ).
- بحث هجين (متجهي + كلمات) ثم إعادة ترتيب عند توفرها.
- أرفق المقاطع المسترجعة مع أرقام مراجع واطلب من النموذج الاستشهاد بها.
- إن لم تكن الإجابة في المصادر، يجب أن يقول النموذج ذلك.
- اختبر بمجموعة أسئلة ثابتة (≥ 20) وسجّل الدقة قبل وبعد أي تغيير.

## الوكلاء والأدوات
- كل أداة: اسم واضح، وصف يشرح متى تُستخدم، مخطط مدخلات صارم.
- الأدوات المدمّرة (حذف، دفع، إرسال) تتطلب تأكيدًا بشريًا.
- حدّ أقصى لعدد الخطوات، وسجّل كل خطوة (tracing).

## الأمان
- عامل مخرجات النموذج كمدخل غير موثوق: لا تنفيذ كود أو SQL منه مباشرة.
- صفّ البيانات الشخصية قبل إرسالها للنموذج عند الإمكان.
