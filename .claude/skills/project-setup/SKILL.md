# إعداد المشروع

## CLAUDE.md (أنشئه أولًا إن لم يوجد)
اكتبه في ≤ 40 سطرًا ويحتوي فقط:
1. وصف المشروع في سطرين + اللغة الأساسية للمستخدمين.
2. التقنيات والإصدارات (إطار، قاعدة بيانات، إدارة حالة).
3. أوامر التشغيل: install / dev / test / lint / build.
4. بنية المجلدات المهمة في 5 أسطر.
5. القواعد الثابتة (مثل: كل النصوص عبر l10n، لا any).
6. ما لا يجب لمسه (ملفات مولّدة، أسرار).

## الهيكل
- README.md قصير للبشر، CLAUDE.md للأداة. لا تكرر بينهما.
- .env.example بكل المتغيرات وقيم وهمية.
- .gitignore مناسب للتقنية.
- .claude/skills/ للمهارات الخاصة بالمشروع.
- مجلد docs/decisions/ لقرارات معمارية (ADR) بصيغة: السياق، القرار، البدائل.

## الأدوات
- أضف lint + format + type-check + test في package.json أو Makefile.
- أضف CI بسيط (GitHub Actions) يشغّل الأربعة عند كل PR.

## قبل الانتهاء
- شغّل أمر التثبيت والاختبار مرة واحدة للتأكد أن الهيكل يعمل.
