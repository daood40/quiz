# الأداء

## القياس أولًا
- شغّل Lighthouse (mobile) وسجّل LCP/INP/CLS وحجم JS قبل أي تعديل.
- حدّد أكبر 3 مشاكل بالأثر، وعالجها بالترتيب. لا تحسين بلا قياس.

## الأكثر أثرًا عادة
1. الصور: صيغ AVIF/WebP، أبعاد صريحة، loading=lazy لغير المرئي، LCP image بـ fetchpriority=high.
2. JavaScript: تقسيم الكود بالمسار، حذف مكتبات ثقيلة (moment→date-fns، lodash كامل→دوال مفردة)، تحليل الحزمة.
3. الخطوط: font-display=swap، تحميل مسبق للخط الأساسي، subset عربي فقط.
4. CSS الحرج مضمّن، والباقي مؤجل.
5. التخزين المؤقت: Cache-Control طويل للأصول المُجزّأة، وCDN.
6. الخادم: TTFB < 200ms عبر كاش أو ISR أو Edge.

## في التطبيق
- تجنب إعادة العرض غير الضرورية (memo، keys ثابتة، virtualization للقوائم).
- لا عمل ثقيل في الخيط الرئيسي؛ Web Worker.

## بعد التعديل
- أعد القياس وأرفق الأرقام قبل/بعد في الرد.
