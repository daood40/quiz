# خط التعلم الآلي

- ابدأ بخط أساس بسيط (LogisticRegression/GradientBoosting) قبل أي شبكة عصبية.
- قسّم البيانات قبل أي معالجة (train/val/test) وثبّت random_state. لا تسريب: fit على train فقط.
- Pipeline واحد يضم المعالجة + النموذج ليُحفظ ويُنشر كوحدة.
- المقياس يتبع المشكلة: F1/PR-AUC للبيانات غير المتوازنة، MAE/RMSE للانحدار. أرفق مصفوفة الالتباس.
- سجّل التجارب (MLflow أو ملف JSON بسيط): المعاملات، المقاييس، بصمة البيانات.
- ضبط المعاملات بـ Optuna أو RandomizedSearch مع تحقق متقاطع؛ لا grid ضخم.
- PyTorch: حلقة تدريب واضحة، mixed precision على GPU، حفظ أفضل checkpoint بالتحقق.
- الحفظ: joblib/ONNX + ملف بيانات وصفية (إصدار، مقاييس، تاريخ).
- النشر: FastAPI بمسار /predict مع تحقق pydantic ومهلة، أو TFLite/CoreML للجوال.
- المراقبة: سجّل توزيع المدخلات والتنبؤات لاكتشاف الانحراف.
- الرد: جدول المقاييس، أهم الميزات، القيود، وخطوة التحسين التالية.
