# تطبيقات Flutter العربية

## قبل أي كود
1. افحص pubspec.yaml وبنية lib/ الحالية والتزم بنفس الأسلوب (إدارة الحالة، التنقل).
2. لا تضف حزمة جديدة إن كانت موجودة بديلة في المشروع.

## اللغة والاتجاه
- لا تستخدم left/right أبدًا؛ استخدم start/end وEdgeInsetsDirectional وAlignmentDirectional.
- استخدم Directionality.of(context) عند الحاجة، ولا تفرض ltr.
- كل نص للمستخدم يمر عبر ملفات الترجمة (l10n/intl)، لا نصوص ثابتة داخل الويدجت.
- التواريخ والأرقام عبر intl مع locale المستخدم.
- أضف خط عربي مناسب (مثل Cairo أو IBM Plex Arabic) في ThemeData.

## البنية
- شاشة = ملف واحد، المنطق في Controller/Notifier منفصل.
- النماذج غير قابلة للتغيير (immutable) مع copyWith.
- التخزين المحلي عبر طبقة Repository، لا وصول مباشر من الويدجت.

## الجودة
- استخدم const حيثما أمكن، وKeys للقوائم.
- القوائم الطويلة: ListView.builder فقط.
- معالجة حالات: تحميل / فارغ / خطأ لكل شاشة بيانات.
- شغّل `flutter analyze` بعد التعديل وأصلح كل التحذيرات.
- اكتب widget test واحد على الأقل لكل شاشة جديدة.

## الإخراج
- عند الانتهاء، اذكر الملفات المعدّلة وأي خطوة يدوية مطلوبة (مثل flutter pub get أو تعديل AndroidManifest).
