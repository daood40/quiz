# الوصول و SEO

## الوصول
- كل صورة لها alt (أو alt="" للزخرفية). كل حقل له label.
- التنقل بلوحة المفاتيح لكل شيء تفاعلي، وfocus-visible ظاهر.
- تباين ≥ 4.5:1، أهداف لمس ≥ 44px.
- العناوين متسلسلة (h1 واحد). landmarks دلالية.
- النوافذ المنبثقة: حبس التركيز، إغلاق بـ Esc، aria-modal.
- شغّل axe واجعل النتائج الحرجة صفرًا.

## SEO
- title فريد ≤ 60 حرفًا، description ≤ 155، لكل صفحة.
- عنوان H1 واحد يطابق نية البحث.
- canonical، Open Graph، وhreflang لكل لغة (ar/en) مع x-default.
- JSON-LD مناسب (Article، Product، FAQ، Organization).
- sitemap.xml وrobots.txt، وروابط داخلية بنص وصفي.
- URL قصير ومقروء؛ للعربية يُفضّل slug لاتيني أو عربي مشفر باتساق.
- الصفحات المعروضة في العميل فقط تحتاج SSR/SSG لتُفهرس.

## الرد
- قائمة بما أُصلح، وما يحتاج محتوى من المستخدم (نصوص، صور).
