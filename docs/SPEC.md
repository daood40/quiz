# مواصفة المنتج — منصة الأسئلة (Quiz Platform)

آخر تحديث: 2026-09-09 · المصادر: `docs/ARCHITECTURE.md`، `docs/API.md`، `memory/FEATURES.md`، `memory/ARCHITECTURE.md`، `memory/PROJECT_MEMORY.md`. هذه الوثيقة تصف ما هو مبنيّ ومختبَر فعلًا، لا ما هو مخطط.

## 1. الغرض
منصة أسئلة ومسابقات ثنائية اللغة (عربي/إنجليزي) يلعب فيها المستخدم جولات أسئلة بأنواع متعددة، ويتنافس مع الآخرين عبر لوحات متصدرين وتحديات وبطولات، بينما يحكّم الخادم كل إجابة ويحسب النقاط. المشكلة التي تحلّها: تطبيقات الأسئلة العربية إمّا محدودة الأنواع أو تحسب النتيجة على الجهاز فيسهل التلاعب بها.

## 2. المستخدمون
| الشريحة | ما يريده | القيود |
|---|---|---|
| لاعب فردي (13+) | جولة سريعة، تحدٍّ يومي، تتبّع تقدّمه | هاتف متوسط، شبكة متقطعة، عربي RTL أولًا |
| لاعب اجتماعي | تحدي الأصدقاء برمز، مجموعات، بطولات | يحتاج حسابًا مسجّلًا (لا زائر) |
| زائر | تجربة بلا تسجيل | حتى `GUEST_MAX_QUESTIONS` سؤالًا، تقدّم مؤقت، حسابه يُحذف بعد 30 يومًا إن لم يلعب |
| محرّر/مشرف/مدير | إدارة بنك الأسئلة والمستخدمين والبلاغات والإعدادات | أدوار RBAC خمسة: user, editor, moderator, admin, super_admin |

## 3. المنصات
كود واحد لثلاث قنوات:
- **الويب**: React 18 + Vite، يُخدَم من خادم Fastify نفسه (SPA fallback).
- **PWA**: manifest + service worker (offline shell، تحديث بموافقة المستخدم). نسخة GitHub Pages تعمل بمحرّك داخل المتصفح (`VITE_DEMO=1`) بلا خادم؛ الميزات الاجتماعية فيها غير متاحة.
- **Android/iOS**: Capacitor 7 (`web/android`, `web/ios`) — نفس حزمة الويب داخل WebView مع جسر أصلي (`web/src/native.ts`): اهتزاز، مشاركة عبر لوحة النظام، تذكير يومي محلي اختياري، شريط الحالة، زر الرجوع، Deep links. لا SDK طرف ثالث، لا إعلانات، لا تتبّع.

## 4. الميزات حسب الوحدة

### 4.1 الحسابات (auth, users)
- تسجيل بالبريد + اسم مستخدم + كلمة مرور (8 أحرف على الأقل)، اسم ظاهر اختياري، لغة، دولة.
- دخول بالبريد أو اسم المستخدم؛ قفل مؤقت 15 دقيقة بعد 10 محاولات فاشلة.
- جلسة زائر بلا بيانات؛ تحويلها لحساب غير مدعوم (يُنشئ حسابًا جديدًا).
- JWT وصول 15 دقيقة + رمز تحديث دوّار 30 يومًا؛ إعادة استخدام رمز محروق تُبطل كل جلسات المستخدم.
- استعادة كلمة المرور وتأكيد البريد برموز أحادية الاستخدام عبر بريد Resend (أو `log` في التطوير).
- تعديل الملف: الاسم الظاهر، صورة رمزية (رمز تعبيري)، اللغة، الدولة، المنطقة الزمنية.
- تصدير بياناتي (JSON) وحذف الحساب (تجهيل فوري؛ تفاصيله في `web/src/pages/legal.tsx`).

### 4.2 محرّك الأسئلة (questions/engine)
- 80 نوع سؤال على 13 عائلة تفاعل: single_choice, multi_choice, text, numeric, ordering, matching, categorization, hotspot, grid, confidence, flashcard, unscored, submission، بالإضافة إلى composite.
- لكل عائلة: `validate` (بنية ودلالة)، `score` (نتيجة، نسبة 0–1، درجات جزئية اختيارية)، `present` (إزالة الإجابات الصحيحة وخلط الخيارات).
- مطابقة نصية تطبّع العربية (تشكيل، همزات، تاء مربوطة، ألف مقصورة) مع تسامح إملائي قابل للضبط؛ مطابقة رقمية تفهم الكسور والنسب والأرقام الهندية.
- الواجهة تختار العارض حسب العائلة من `GET /quizzes/question-types`، فإضافة نوع جديد لا تتطلب تغييرًا في الواجهة غالبًا.

### 4.3 أوضاع اللعب (quizzes)
| الوضع | القاعدة | يدخل الترتيب؟ |
|---|---|---|
| تدريب | بلا وقت، تصحيح فوري مع الشرح | لا |
| موقّت | مهلة لكل سؤال، مكافأة سرعة، مساعدات | نعم |
| سرعة | 10 ثوانٍ للسؤال، مكافأة سرعة مضاعفة | نعم |
| البقاء | إجابة خاطئة واحدة تنهي الجولة | نعم |
| المعرفة | أسئلة صعبة، 60 ثانية، بلا مكافأة سرعة | نعم |
| اليومي | الأسئلة نفسها للجميع، محاولة واحدة يوميًا | نعم |
| مراجعة الأخطاء | يعيد الأسئلة التي أخطأ فيها المستخدم | لا |
| الأسئلة المحفوظة | يعيد ما حفظه المستخدم | لا |
| اختبار مُعدّ | مجموعة ثابتة يحدّدها المدير | نعم |

- الخادم يختار الأسئلة (تصنيف، صعوبة، لغة، نوع، وسوم؛ غير المُجاب أولًا؛ بوابة جودة)، ويحسب الوقت من طوابعه الزمنية، ويرفض التكرار، ويعلّم المحاولات المشبوهة (أسرع من `antiCheatMinAnswerMs`، إجابات غريبة).
- المساعدات (مرة لكل جولة): 50:50، +20 ثانية، اسأل الجمهور (توزيع حقيقي من إحصاءات الخيارات).
- الإرسال في معاملة واحدة: ملء المتخطّى، الإجماليات، XP، المستوى، السلسلة حسب المنطقة الزمنية، إحصاءات المستخدم والتصنيف، لوحات المتصدرين، الإنجازات، الإشعارات، ثم إغلاق التحدي/البطولة.
- استئناف المحاولة بعد انقطاع الشبكة (`GET /quizzes/attempts/:id`)؛ المؤقّت يتوقف أثناء الانقطاع.
- الإبلاغ عن سؤال بسبب من 7 أسباب؛ أرشفة سؤال بإجابة خاطئة تعيد نقاط المتضررين هذا الشهر تلقائيًا.

### 4.4 التحفيز (gamification, stats, achievements)
- نقاط خبرة لكل إجابة صحيحة ولكل اختبار مكتمل؛ مستويات بمنحنى قابل للضبط من الإعدادات.
- سلسلة يومية مع حماية السلسلة (streak freezes) وتذكير قبل فقدها (إشعار داخل التطبيق بعد ~20 ساعة خمول).
- إنجازات مبنية على معايير، مع إشعار عند تحقيقها.
- إحصائيات شخصية: الإجماليات، الدقة، أفضل/أضعف تصنيف، نشاط 90 يومًا.

### 4.5 الاجتماعي (friends, groups, challenges, monthly, tournaments)
- أصدقاء: طلب بالاسم، قبول/رفض، إزالة؛ لوحة متصدرين للأصدقاء.
- مجموعات: إنشاء، انضمام برمز أو مجموعة عامة، دعوة، مغادرة؛ لوحة للمجموعة.
- تحديات: مجموعة أسئلة ثابتة متطابقة للجميع، رمز مشاركة، دعوات بالاسم، انتهاء تلقائي.
- تحدٍّ شهري يُنشأ ويُغلق تلقائيًا، مشاركة واحدة لكل مستخدم شهريًا، سجل تاريخي.
- بطولات إقصائية: تسجيل، بذر وبناء الجولات، مباريات كمحاولات، إعفاء (bye) وانسحاب، بطل.

### 4.6 لوحات المتصدرين (leaderboards)
- الترتيب في كل مكان: `points DESC, total_time_ms ASC, correct DESC, last_scored_at ASC`.
- النطاقات: عالمي، دولة، تصنيف، يومي/أسبوعي/شهري، مجموعة، أصدقاء، تحدٍّ، تحدٍّ شهري، بطولة.
- `leaderboard_scores` مصدر الحقيقة؛ اللوحات الساخنة مخزّنة مؤقتًا في `leaderboard_snapshots` مع TTL (إعداد `leaderboardCacheTtlSec`) وإبطال عند الكتابة.

### 4.7 الإدارة (admin)
- لوحة رئيسية: المستخدمون، النشطون خلال 24 ساعة، الأسئلة حسب الحالة، محاولات اليوم، البلاغات المفتوحة، المحاولات المشبوهة.
- الأسئلة: إنشاء/تعديل مع إصدارات (`question_versions`)، تحقق، حالة (مسودة، بانتظار المراجعة، معتمد، مرفوض، مؤرشف)، إجراءات جماعية، إعادة حساب الجودة.
- استيراد JSON/CSV (صارم أو جزئي مع أخطاء لكل صف) وتصدير بالفلاتر.
- المستخدمون: بحث، حالة (نشط/موقوف/محظور)، أدوار.
- البلاغات: حل/تجاهل. مكافحة الغش: مراجعة المحاولات المُعلَّمة أو مسح علاماتها.
- إعدادات حيّة في `app_settings`: الوقت الافتراضي للسؤال، حجم الاختبار، XP، حد الاختبارات اليومي، أسئلة الزائر، TTL المتصدرين، أقل زمن إجابة، مكافأة السرعة، وضع الزائر، فتح التسجيل، وضع الصيانة، تفعيل الذكاء الاصطناعي.
- سجل تدقيق لكل إجراء إداري وأمني.

### 4.8 مسودات الذكاء الاصطناعي (ai)
- يولّد مسودات اختيار من متعدد إلى طابور المراجعة فقط؛ لا يُنشر شيء دون اعتماد بشري.
- معطّل ما لم يُضبط `AI_PROVIDER` و`AI_API_KEY` على الخادم ويُفعَّل من الإعدادات.
- حصص يومية لكل محرّر وللمنصة (`AI_DAILY_PER_USER`, `AI_DAILY_PLATFORM`) بقفل استشاري يمنع التجاوز المتزامن.
- **SOURCE_LOCK**: التصنيفات الدينية لا تُولَّد آليًا، واعتماد سؤال فيها يتطلب مصدرًا.

## 5. المتطلبات غير الوظيفية

### 5.1 الأمان
- الصلاحيات والتصحيح والنقاط على الخادم فقط؛ الواجهة تعرض.
- الإجابات الصحيحة لا تُرسل إلى العميل قبل الإرسال (إلا في الأوضاع غير الموقّتة كتغذية راجعة).
- كلمات المرور bcrypt (`BCRYPT_ROUNDS`)، رموز التحديث مجزّأة في قاعدة البيانات، HTTPS إلزامي في الإنتاج مع HSTS وCSP.
- تحديد معدل الطلبات (`RATE_LIMIT_*`) وقفل الدخول بعد 10 محاولات.
- لا مفاتيح سرّية في `web/`؛ الأسرار عبر البيئة فقط. `/metrics` مقفل بـ`METRICS_TOKEN`.
- ردود الأخطاء موحّدة `{ error: { code, message } }` ولا تسرّب تفاصيل داخلية.

### 5.2 الأداء
- الواجهة: skeleton لكل شاشة أثناء التحميل، حزم مجزّأة مع تخزين سنة للأصول ذات البصمة، خط Cairo خارج المسار الحرج.
- الخادم: pool اتصالات PostgreSQL، لوحات المتصدرين مخزّنة مؤقتًا، مهام خلفية بأقفال استشارية لا تتكرر بين النسخ.
- اختبار الحمل على `/api/v1/attempts` ما زال متبقيًا (`memory/TODO.md` P1).

### 5.3 الإتاحة
- WCAG AA: تباين ≥ 4.5:1، لوحة مفاتيح كاملة (المفاتيح 1–4 للإجابة وEnter للإرسال)، `aria-live` للحالات، خط كبير اختياري، تقليل الحركة.
- axe في دخان CI: 0 مخالفات على 62 مسحًا.

### 5.4 اللغة والاتجاه
- كل نص ظاهر من `web/src/i18n.tsx`؛ صيغ الجمع العربية الست عبر `pluralize`.
- RTL/LTR حسب اللغة قبل أول رسم؛ خصائص CSS منطقية فقط؛ الأرقام لاتينية.
- الأسئلة ثنائية اللغة في قاعدة البيانات (`{ar, en}`) والواجهة تختار حسب اللغة مع بديل.

### 5.5 الموثوقية والتشغيل
- ترحيلات SQL مرقّمة تُطبَّق عند الإقلاع مع بصمة sha256؛ بذر أول تشغيل اختياري (`SEED_ON_BOOT`).
- `/health` (حيّ) و`/ready` (قاعدة البيانات والمهام سليمة).
- نسخ احتياطي ليلي `scripts/backup.sh` بدورة 14 يومًا، مع تشفير أو نسخة خارجية إلزامية في الإنتاج.
- سياسة احتفاظ منفَّذة في `jobs/scheduler.ts`: زوار لم يلعبوا 30 يومًا، أحداث التحليل 180 يومًا، سجلات التدقيق 400 يوم، الرموز المنتهية 7 أيام.

## 6. خارج النطاق (الإصدار الحالي)
- إشعارات Push عبر FCM/APNs (التذكير الحالي محلي على الجهاز فقط).
- MFA وتسجيل الدخول بطرف ثالث (Google/Apple).
- CAPTCHA عند التسجيل.
- محدّد معدل موزّع (Redis) لأكثر من نسخة خادم.
- دردشة حرّة بين اللاعبين أو محتوى من المستخدمين غير البلاغات.
- مدفوعات أو اشتراكات.
- تحويل حساب الزائر إلى حساب مسجّل مع الاحتفاظ بالتقدّم.

## 7. معايير الإصدار
- `npm run lint` و`npm test` (119 اختبار خادم على PostgreSQL حقيقية) و`npm run build` ودخان `npm run e2e --workspace=web` كلها خضراء.
- E2E الكامل 11/11 ودخان + axe 17/17 في CI.
- كل شاشة بحالاتها الأربع: تحميل، فراغ، خطأ مع إعادة محاولة، بيانات.
- لا نص ظاهر خارج `i18n.tsx`، ولا خصائص CSS فيزيائية، ولا مفاتيح سرّية في `web/`.
- صفحتا الخصوصية وحذف الحساب عامتان بلا تسجيل، ومطابقتان للكود.
- للمتاجر: الخادم منشور و`CORS_ORIGIN` يشمل `https://localhost,capacitor://localhost`، والتطبيق موقّع، وحساب تجريبي للمراجعين (تفاصيل `docs/STORE_SUBMISSION.md`).
