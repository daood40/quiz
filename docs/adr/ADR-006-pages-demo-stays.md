# ADR-006 — بقاء الـ Demo الثابت على GitHub Pages كوضع تدريب/معاينة

**الحالة:** معتمد — مطبَّق.

## السياق
التوجيه v2 (§29 ADR-006): الـ Demo المنشور يبقى كمعاينة واجهة (Practice
Mode بلا حساب)، والإنتاج يتطلب Backend. البديل المرفوض: إزالة الـ Demo.

## القرار
- النشر التلقائي عبر `.github/workflows/pages.yml`: كل push يبني الواجهة
  بوضع `VITE_DEMO=1` وينشرها على `https://daood40.github.io/quiz/`.
- نسخة الـ Demo تشغّل **محرك الأسئلة الحقيقي نفسه** (`web/src/demo/engine/`
  نسخة العائلات ذاتها) على بنك مدمج، والتقدم في localStorage.
- **حدود ملزمة للـ Demo:** لا حسابات، لا ترتيب علني، لا نقاط تنافسية —
  فلا يتعارض مع ADR-001؛ الميزات الاجتماعية تظهر فقط في النسخة الكاملة.

## الأثر
واجهة `IS_DEMO` في `web/src/api.ts` هي مفتاح التبديل الوحيد؛ أي ميزة
تنافسية جديدة يجب أن تكون خلف هذا المفتاح (مخفاة في الـ Demo).
